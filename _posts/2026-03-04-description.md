# Tutorial 2: Molecular Dynamics Simulations 
This tutorial page is for Tutorial 2: Molecular Dynamics Simulations as a part of module "CH932: Computational Chemistry" worth 10 credits and consists of 14 lectures and 2 x 3h tutorials.

## Prerequisites
- Basic knowledge of [Linux command line](https://ubuntu.com/tutorials/command-line-for-beginners#3-opening-a-terminal)
- GROMACS installed on your machine or access to ARCHIE-WeSt HPC
- Visualisation software (e.g., VMD) installed or access to visualisation tools on ARCHIE-WeSt
- Basic understanding of molecular dynamics concepts

## Learning Objectives
By the end of this tutorial, students will be able to
- Understand the fundamental concepts and workflow of a typical of molecular dynamics simulations.
- Set up and run a basic molecular dynamics simulation using GROMACS in a small group of students.
- Analyse the simulation results by presenting a written report.
